## Prevention of Model-Generated Evidence

Starting from T04/T05, all acceptance evidence (Commit SHA, Tree SHA, Parent SHA, Commit Message, Tracked File Count, SHA-256 hashes, Exit Codes) must be generated by `scripts/capture-acceptance-evidence.ps1` and `scripts/run-acceptance-step.ps1` and read directly from `evidence-manifest.json` and `*.result.json` files. Manual typing or model auto-completion of hash strings or commit messages is strictly prohibited.
