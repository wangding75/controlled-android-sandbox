## Prevention of Model-Generated Evidence

Starting from T04, all acceptance evidence (Commit SHA, Tree SHA, Parent SHA, Tracked File Count, SHA-256 hashes, Exit Codes) must be generated by `scripts/capture-acceptance-evidence.ps1` and read directly from `evidence-manifest.json` and artifact hash files. Manual typing or model auto-completion of hash strings is strictly prohibited.
