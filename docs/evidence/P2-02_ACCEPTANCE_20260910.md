## Root cause and implementation contract

The first post-application failure was a UI-thread wait in
`AutofillManager` (`SyncResultReceiver.getIntResult`) because API 36's
`IAutoFillManager` is an oneway Binder interface and its `IResultReceiver`
callback was not completed. The Xiaomi runtime does not expose
`IResultReceiver.Stub.asInterface(IBinder)` to reflection; this was captured as
`NoSuchMethodException`, not inferred. The fix sends `send(int, Bundle)` over
the generated AIDL wire contract (descriptor
`com.android.internal.os.IResultReceiver`, transaction 1, oneway), preserving
the Binder callback boundary used by NBB/VA rather than returning a guessed
local value. `USE_BIOMETRIC` is declared for the guest process so the platform
permission check does not abort Chrome startup.

Reference decisions and the split/native path evidence are recorded in
[`P2-02_REFERENCE_DECISION.md`](../plans/P2-02_REFERENCE_DECISION.md).
